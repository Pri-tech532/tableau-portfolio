## 👋 About This Repository

This repository is a collection of my Tableau projects. Each project covers the full workflow: choosing a dataset, cleaning and preparing the data, building calculated fields, designing interactive dashboards, and turning the results into insights.

## 🔄 My Project Workflow

1. **Define the question:** start with a business question, not a chart
2. **Understand the data:** check columns, types, missing values and limits
3. **Prepare:** build calculated fields and fix messy columns
4. **Build:** create one sheet per question
5. **Assemble:** arrange sheets into a dashboard with KPIs and filters
6. **Polish:** consistent colours, clear titles, no clutter
7. **Document:** write the insights, limitations and next steps

## 🚀 How to Open a Project

1. Open a project folder and download the `.twbx` file
2. Open it in **Tableau Public** or **Tableau Desktop** (the data is packaged inside)
3. Click chart elements to explore. Click an empty area to reset filters
